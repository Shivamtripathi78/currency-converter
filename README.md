# 💱 Currency Converter

A responsive currency converter web application that retrieves exchange rates from the Frankfurter API and converts amounts between supported currencies.

## ✨ Features

- 💱 Convert between supported currencies
- 🌍 Dynamically load available currencies
- 🔄 Swap source and target currencies
- 📈 Display exchange rates
- 🕒 Show the exchange-rate date
- 🔢 Validate user input
- ⚠️ Handle API and network errors
- 📋 View recent conversion history
- 📱 Responsive design for mobile and desktop
- 🎨 Modern, user-friendly interface
- 🔑 No API key required

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Fetch API
- Frankfurter Exchange Rate API
- Intl.NumberFormat

## 🚀 Getting Started

### Prerequisites

- A modern web browser
- Internet connection

### Installation

Clone the repository:

```bash
git clone https://github.com/Shivamtripathi78/currency-converter.git
```

Navigate to the project directory:

```bash
cd currency-converter
```

Open `index.html` in your browser.

Alternatively, use the Live Server extension in Visual Studio Code.

## 📖 How to Use

1. Open the application.
2. Enter the amount you want to convert.
3. Select the source currency.
4. Select the target currency.
5. Click **Convert Currency**.
6. View the converted amount and exchange rate.
7. Use the swap button to reverse the selected currencies.
8. Review or clear recent conversions.

## 🌐 Exchange Rate Data

This project uses the [Frankfurter API](https://frankfurter.dev/).

The API provides reference exchange rates from central banks and other sources. Rates are updated according to provider publishing schedules and are not guaranteed to represent live trading or bank transaction rates.

An internet connection is required to retrieve currencies and exchange rates.
